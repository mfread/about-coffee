The idea for this web app was borne from wanting to understand more about coffee types (Capuchino, Piccolo, Macchiato etc) while sitting in a cafe by myself one day feeling somewhat bored.

The app runs on all devices, from smartphones and tablets, through to laptops and PC's.

The QR-Code.png file can, with written permission from me, be used to point back to this site for quick and easy access.

If you're a cafe owner and would like to display my QR code please reach out. Likewise if you'd like to white label my app.
